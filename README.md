# MesOffres 📱

**MesOffres** est une application Android conçue pour faciliter la gestion des offres d'emploi et de stage, le suivi des candidatures et l'organisation des prochaines échéances.

## ✨ Fonctionnalités

- 📋 Consultation et gestion des offres d'emploi et de stage
- ✏️ Ajout et modification des offres
- ⭐ Gestion des offres favorites
- 📨 Préparation et partage de lettres de candidature
- 📊 Suivi des candidatures selon leur statut
- 🔔 Gestion des rappels et des échéances
- 👤 Espace profil
- 💾 Stockage local des données pour une utilisation hors ligne

## 🛠️ Technologies utilisées

- **Langage :** Kotlin
- **Interface :** Jetpack Compose
- **Architecture :** MVVM
- **Base de données locale :** Room
- **Navigation :** Navigation Compose
- **Gestion d'état :** ViewModel et Kotlin Flow

## 🏗️ Architecture

Le projet suit le modèle **MVVM** :

- **Model :** représente les données de l'application.
- **View :** affiche les écrans avec Jetpack Compose.
- **ViewModel :** gère l'état et la logique de présentation.
- **Repository :** centralise l'accès aux données.

## 🚀 Installation

1. Clonez le dépôt :

   ```bash
   https://github.com/thiernolkb733/nosoffres.git
   ```

2. Ouvrez le projet dans Android Studio.
3. Laissez Gradle synchroniser les dépendances.
4. Lancez l'application sur un émulateur ou un appareil Android compatible.
